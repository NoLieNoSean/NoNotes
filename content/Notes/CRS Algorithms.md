6/8: introduction to algorithms, nothing much was covered except the core of the course (finding and optimizing algorithms)
8/8: Asymptotic notation: big O, omega, theta, solving recurrence relations with recursion trees
13/8: I missed this class but I think master theorem was covered, a formula for solving recurrence relations.
20/8: Divide and conquer technique, algorithms for finding convex hull were discussed: Jarvis search algorithm, and divide&conquer algorithm
22/8: Quick select algorithm, to find the ith smallest element in a list of distinct numbers.
29/8: Merge sort, and also my notes say we were talking about finding an algorithm for pair of shortest distance in a set of points, a divide and conquer idea was brought up but we didn't actually come up with anything concrete? Weird
3/9: Introducing new data structures to get faster algorithms. BST (binary search tree) was introduced, using BST instead of an array makes insertion sort go from a O(n^2) to O(n log n) algorithm. Quicksort and Shellsort were also discussed (I don't really understand shellsort tho tbh)
5/9: Max-heap and min-heap data structures and how they are used in Heapsort. Also proof that a sorting algorithm cannot be faster than O(n log n).
10/9: Don't remember if there was a class on this day but I also have no notes either 💀(NoNotes reference!??🗣️)
12/9: Hash table: a way to store key/value pairs and access/insert/delete them in O(1) time. The idea is to map keys to an array {0...m-1} with a hash function, but key collision issues arise. Linked lists are used to solve this problem. Also talked about how SUH (simple uniform hashing) functions are best (because there's roughly an equal chance of a key mapping to any of the m slots.)
17/9: Hash table with Open Addressing instead of linked lists. One slot of the {m} array only ever has one key, if a collision is found, a new slot is found every time with a special kind of hash function facilitating this.
19/9: Greedy algorithms, a technique for optimization: involves finding optimal solutions to a SUBproblem and using it to find an optimal solution to the problem. Example of a greedy algorithm for finding minimal spanning tree of a graph was covered.
