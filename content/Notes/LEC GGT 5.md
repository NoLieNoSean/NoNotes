[!Proposition]
If $|\mathrm{Tr}(A)|\leqslant 2$, then there is exactly one fixed point which is in $\mathbb{H}$. Elliptic
If $|\mathrm{Tr}(A)|=2$, then there is exaclt one fixed point on $\mathbb{R}\cup \{ \infty \}$. Parabolic
If $|\mathrm{Tr}(A)|> 2$, then there are two distinct fixed point on $\mathbb{R}\cup \{ \infty \}$. Hyperbolic. 
	Any hyperbolic element has an invariant geodesic called the axis. This is unique.

Ping pong lemma
